Welcome to Lampstand

Lampstand installs and configures system packages (Apache, PHP, MySQL, phpMyAdmin, Node.js) and modifies system files (/etc/apache2, /etc/hosts, /var/www/html permissions, user/group membership) on your behalf, using standard Ubuntu apt repositories.

Ubuntu only. Lampstand is currently built and tested for Ubuntu and Ubuntu-based systems (Kubuntu, Xubuntu, Ubuntu MATE, Linux Mint, Pop!_OS, ...). On other distributions, including plain Debian, some or all install steps will fail.
